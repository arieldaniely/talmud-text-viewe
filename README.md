# דף פתוח — Talmud Text Viewer

אתר קל לצפייה בגמרא ובמפרשים הראשיים. כל זרם נשמר כמחרוזת Unicode רציפה,
עם מפת טווחים ומיקומים המשחזרת את קווי הבסיס, רוחבי המילים, שינויי גודל האותיות וההתרחבות של הזרמים בדף המקורי. בתצוגה יש רכיב טקסט אחד לכל זרם; הטווחים שבתוכו ממוקמים לפי המקור. רש״י, תוספות וההגהות שבתוכם כלולים; בנדרים
כלולים גם ר״ן ופירוש הרא״ש, ובשקלים המפרשים המחליפים את רש״י ותוספות.
רשב״ם נכלל במקום רש״י בעמודים המתאימים בבבא בתרא.
גם כותרת הדף המקורית (שם הפרק, המסכת ומספר הדף), מסורת הש״ס ועין משפט
נר מצווה כלולים ומוצגים במיקומם המקורי, וניתנים לחיפוש ולהעתקה.

האיורים מיוצגים בסימון טקסט ומיקום בלבד, ורק בתוך הזרמים שנכללו.
הקורפוס מאוחסן כטקסט JSON דחוס ב־gzip, והדפדפן טוען מסכת לפי הצורך.
יש ניווט בין דפים, חיפוש במסכת, שמירת מקום, העתקה, הגדלת הדף כולו ומצב כהה.

## צפייה מקומית

מתיקיית המאגר:

```sh
python -m http.server 8766 --bind 127.0.0.1
```

פתחו `http://127.0.0.1:8766/`. נדרש דפדפן עדכני עם `DecompressionStream`.
הפונטים Romm Vilna לגמרא ולכותרות ו־Mekorot לכתב רש״י כלולים בחבילה
ברישיון פתוח, ונטענים מקומית. Noto Serif Hebrew משמש פונט גיבוי חיצוני.

## הכנה ל־GitHub Pages

מאגר זה מוכן להעלאה עצמאית בשם `talmud-text-viewer`. הוא לא פורסם.
לאחר אישור פרסום: יוצרים מאגר ציבורי, מעלים אליו את תיקייה זו בלבד,
מגדירים ב־Settings → Pages את GitHub Actions, ומפעילים ידנית את
התהליך `Publish text viewer`. התהליך אינו מופעל אוטומטית בדחיפה למאגר.

אין לכלול במאגר את תיקיות המקור, ה־PDF, התמונות, הפונטים של מהדורת המקור או פלטי
ה־SVG של הפרויקט המלא. המידע באתר כולל טקסט, הפניות והגהות, ומיקומים
מספריים של טקסט וסימוני איורים. צורות האותיות של הפונטים החדשים שונות מן המקור; מיקומי הטקסט ושבירת השורות נשמרים.
