# דף פתוח — Talmud Text Viewer

אתר קל לצפייה בגמרא ובמפרשים הראשיים. טקסט הגמרא מיובא מקומית מספריא
מהגרסה הלא מנוקדת `William Davidson Edition - Aramaic`, לפי מסכת ודף.
הוא מסודר מחדש בתוך אזור הגמרא המקורי. [מקורות, חריגים והפקה](SEFARIA-SOURCES.md).
כל זרם נשמר כמחרוזת Unicode רציפה,
עם מפת טווחים ומיקומים המשחזרת את קווי הבסיס, רוחבי המילים, שינויי גודל האותיות וההתרחבות של הזרמים בדף המקורי. בתצוגה יש רכיב טקסט אחד לכל זרם; הטווחים שבתוכו ממוקמים לפי המקור. רש״י, תוספות וההגהות שבתוכם כלולים; בנדרים
כלולים גם ר״ן ופירוש הרא״ש, ובשקלים המפרשים המחליפים את רש״י ותוספות.
רשב״ם נכלל במקום רש״י בעמודים המתאימים בבבא בתרא.
כותרת הדף המקורית נשמרת. מסורת הש״ס ועין משפט נר מצווה אינם מוצגים, נחפשים או מועתקים.
מדור הגהות הגר״א מושמט מקובצי הנתונים של המציג. בדיקת הפרסום חוסמת קובץ שבו המדור נשאר.

איורי ספריא משובצים במקומות המתאימים בדף. כשמסגרת אחת כוללת כמה איורים,
הם מוצגים בנפרד ובסדר הקריאה. מתחת לדף מופיעה גם תצוגה גדולה של האיורים,
לרבות אלה שאין להם שטח פנוי מתאים בתוך הדף.
הקורפוס מאוחסן כטקסט JSON דחוס ב־gzip, והדפדפן טוען מסכת לפי הצורך.
יש ניווט בין דפים, חיפוש במסכת, שמירת מקום, העתקה, הגדלת הדף כולו ומצב כהה.

## צפייה מקומית

מתיקיית המאגר:

```sh
python scripts/serve-local.py
```

פתחו `http://127.0.0.1:8766/`. נדרש דפדפן עדכני עם `DecompressionStream`.
השרת המקומי כולל את איורי הבדיקה מתיקיית המטמון. בחבילה לפרסום
נכללים קובצי איור עם רישיון שנבדק ברמת הקובץ.
הגמרא, רש״י ותוספות נטענים מקומית בפונט דף וילנה 4.001.
[רישיון וקוד המקור של הפונטים](FONT-NOTICES.md) כלולים במאגר.

## הכנה ל־GitHub Pages

מאגר זה מוכן להעלאה עצמאית בשם `talmud-text-viewer`. הוא לא פורסם.
לאחר אישור פרסום: יוצרים מאגר ציבורי, מעלים אליו את תיקייה זו בלבד,
מגדירים ב־Settings → Pages את GitHub Actions, ומפעילים ידנית את
התהליך `Publish text viewer`. התהליך אינו מופעל אוטומטית בדחיפה למאגר.

אין לכלול במאגר את תיקיות המקור, ה־PDF, התמונות, הפונטים של מהדורת המקור או פלטי
ה־SVG של הפרויקט המלא. המידע באתר כולל טקסט, הפניות והגהות, מיקומים
מספריים ואיורים שהתקבלו מספריא. צורות האותיות של הפונטים החדשים שונות מן המקור. המפרשים שומרים על מיקומיהם; הגמרא מספריא מסודרת מחדש בתוך גבולות השורות המקוריות.

## רש״י ותוספות מספריא

קטעים ברש״י ובתוספות מיובאים מספריא לפי התאמה לנוסח המודפס. קווי הבסיס,
גבולות העמודות וסדר הקריאה נקבעים לפי נתוני הדף המקורי. קטעים שלא זוהו
בוודאות ממשיכים להופיע בנוסח המקומי. [שיטת ההתאמה, מקורות וחריגים](COMMENTARY-MIGRATION.md)
